# cache-simulator

A configurable cache simulator in C++. It models **Direct Mapped**, **N-way Set Associative**
and **Fully Associative** caches with **FIFO** and **LRU** replacement, and reports
**hit ratio, miss ratio, compulsory misses and Average Memory Access Time (AMAT)** for a memory-access trace.

## Build and run
```bash
make                 # builds ./cache_sim  (needs g++)
make traces          # generates sample traces in traces/  (needs python3)
make test            # runs the hand-checked tests

./cache_sim --trace traces/loop.txt --compare
./cache_sim --trace traces/hot_scan.txt --size 128 --block 16 --assoc 2 --policy LRU
```

### Options
| Option | Meaning | Default |
|---|---|---|
| `--trace FILE` | memory access trace (required) | |
| `--size BYTES` | cache size (power of 2) | 1024 |
| `--block BYTES` | block size (power of 2) | 16 |
| `--assoc N` | 1 = direct mapped, N = N-way, 0 = fully associative | 1 |
| `--policy` | `LRU` or `FIFO` | LRU |
| `--hit-time` / `--miss-penalty` | cycles used in AMAT | 1 / 100 |
| `--compare` | run all organizations and both policies in one table | off |

Trace format: one address per line (hex like `0x1A2B` or decimal), optional leading `R`/`W`, `#` for comments.

## How it works
- An address is split into **offset** (block byte), **index** (which set) and **tag** (which block in that set).
- Each set holds `assoc` lines. Direct mapped = 1 line per set; fully associative = 1 set with all lines.
- On a miss, a free line is used first. If the set is full, **LRU** evicts the least recently used line and **FIFO** evicts the oldest loaded line.
- A miss on a block that was never seen before is counted as a **compulsory** miss.
- `AMAT = hit time + miss ratio x miss penalty`

## Results (from my runs, 1 KB cache, 16 B blocks, hit time 1, miss penalty 100)
| Trace | Direct Mapped | 2-way | 4-way | Fully assoc | What it shows |
|---|---|---|---|---|---|
| sequential | 75.00% hit | 75.00% | 75.00% | 75.00% | spatial locality: 1 miss then 3 hits per 16 B block |
| loop | 99.61% | 99.61% | 99.61% | 99.61% | temporal locality: working set fits in the cache |
| random | 1.83% | 1.78-1.79% | 1.67-1.70% | 1.54-1.56% | no locality: nearly everything misses |
| conflict | 0.00% | 0.00% | 99.95% | 99.95% | 4 blocks map to one set: needs 4+ ways |

LRU vs FIFO (`hot_scan` trace, 128 B cache): 2-way LRU gets 49.98% hit vs 31.23% for FIFO,
because LRU keeps the reused "hot" blocks while a streaming scan passes through.

## Tests
`make test` runs small hand-calculated cases (spatial locality, direct-mapped conflict,
2-way removing the conflict, LRU vs FIFO on the pattern A B A C A, and the AMAT formula).

## Limitations
- Simulates hits and misses only: no write policy (write-back/write-through), no multi-level caches, no timing model beyond AMAT.
- Read and write accesses are treated the same.
- Traces are synthetic, generated by `gen_trace.py`, not from a real program.
